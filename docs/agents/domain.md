# Domain docs

This is a single-context repository.

Before working in the repository, read:

- `CONTEXT.md`, when present.
- Relevant decisions under `docs/adr/`, when present.
- The binding product contract in `PRD.md`.

Use terminology defined in `CONTEXT.md`. Do not silently introduce synonyms for established domain concepts.

If proposed work contradicts an ADR, identify the conflict explicitly rather than silently overriding it. Domain documentation and ADRs are created as decisions become durable; their absence is not itself an error.
