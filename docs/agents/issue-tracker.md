# Issue tracker: GitHub

Issues and PRDs for this repository live in GitHub Issues. Use the `gh` CLI from this checkout so the remote resolves to `serpcompany/serp-appspass`.

## Conventions

- Create, read, comment on, label, and close work using `gh issue`.
- Publish planning artifacts and agent-ready todos as GitHub issues.
- Pull requests are not a feature-request or triage surface.
- Use GitHub's native issue dependencies for blocking relationships.
- Apply `ready-for-agent` only after an issue has complete acceptance criteria and no unresolved product decision.
