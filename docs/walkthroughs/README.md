# Agent-assisted QA walkthroughs

These walkthroughs exercise deployed staging as role-based product journeys. They complement automated boundary tests; they do not replace them.

- [`JOHN_DOE_FRESH_AGENT_PROMPT.md`](./JOHN_DOE_FRESH_AGENT_PROMPT.md) starts an invited third-party Publisher inclusion walkthrough with a fresh agent.
- The maintained executable procedure is the user-invoked repo skill `$apps-pass-publisher-walkthrough` under `.agents/skills/`.

The user remains responsible for Operator approval and any Stripe Checkout confirmation. The agent performs developer work and verifies observable results.
