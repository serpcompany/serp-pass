# Home page specification

## Overview

- Target: `apps/web/src/app/page.tsx`
- Reference pattern: Setapp promise, collection preview, how-it-works, pricing CTA
- Interaction model: static server-rendered content and links

## Sections

1. Hero with private-pilot label, one-subscription promise, `$10/month` working price, and Subscriber/Apps CTAs.
2. App preview using actual approved D1 records; never invent product availability.
3. Three Subscriber steps: subscribe, connect, use.
4. Publisher CTA linking to `/submit` and `/docs`.
5. Pilot boundary explaining test mode and external Publisher payments.

## Responsive behavior

- Desktop hero uses asymmetric two-column layout.
- App and step cards use three columns where possible.
- Mobile stacks all content and preserves CTA order.
